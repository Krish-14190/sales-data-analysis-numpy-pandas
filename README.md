# 📊 Sales Data Analysis Using Python, NumPy & Pandas

## 📌 Project Overview
This project focuses on performing practical sales data analysis using Python libraries **NumPy and Pandas**. The objective is to explore sales data, perform statistical calculations, analyze profit and sales performance, and extract meaningful business insights.

This project is part of my continuous learning journey towards becoming a Data Analyst.

## 🛠️ Technologies & Libraries Used
- Python
- NumPy
- Pandas
- Jupyter Notebook

## 📂 Key Analysis & Operations

### 1. Statistical Analysis
- Calculate average sales using Mean.
- Find Median sales.
- Calculate Standard Deviation.
- Identify Minimum and Maximum sales values.

### 2. Sales Performance Analysis
- Classify orders into High Sales and Low Sales based on average sales.
- Analyze sales distribution.

### 3. Profit Analysis
- Identify loss-making transactions.
- Count transactions where Profit is less than zero.
- Analyze profit-related metrics.

### 4. Data Manipulation
- Handle missing values.
- Select and filter DataFrame columns.
- Create new calculated columns.
- Perform numerical operations using NumPy.

## 📈 NumPy Functions Practiced

| Function | Purpose |
|---|---|
| `np.mean()` | Calculate average |
| `np.median()` | Calculate median |
| `np.std()` | Calculate standard deviation |
| `np.max()` | Find maximum value |
| `np.min()` | Find minimum value |
| `np.sum()` | Calculate total |
| `np.where()` | Apply conditional classification |
